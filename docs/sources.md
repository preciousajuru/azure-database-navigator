# Source register

Technical claims are based on official sources actually read and recorded in `src/data/sources.js`. That file is the authoritative register of source IDs, canonical URLs, publication/update dates, verification dates, stated evidence and limitations.

The build appends the complete source table to this page from that register. There is no second manually maintained list to drift back to old hub URLs. The current snapshot contains **54 sources**, checked on **1 November 2026**. Specific feature pages take precedence over broad service summaries; model guidance does not establish API, version, tier or regional support.

The [Compute Navigator repository](https://github.com/preciousajuru/azure-compute-navigator) and [application](https://preciousajuru.github.io/azure-compute-navigator/) are design inspiration and the companion for choosing where an application runs. No source was copied.

Read the [research method](research-method.md) for the evidence policy and [decision model](decision-model.md) for rule boundaries. Supported, conditional, unsupported, unknown and not applicable remain distinct. Unknown is not a reason to reject a service.
