# Screenshot provenance

The PNG files in `screenshots/` are genuine renders of Azure Database Navigator captured with Chromium through Playwright on **1 November 2026**. They show the local static build at `/azure-database-navigator/`; no public deployment is claimed.

## Capture matrix

| Views | Viewport | Theme | Capture |
|---|---|---|---|
| Default assessment | 375, 768, 1024 and 1440 px wide; 1000 px browser height | Light and dark | Full page |
| RAG responsibilities and synchronisation/failure boundaries | 1440 px wide | Light and dark | Actual architecture section |
| Service comparison | 1440 px wide | Light and dark | Full page |

The RAG image uses the documented worked fixture: original documents, authoritative application state and a derived retrieval index. It does not represent a real customer deployment or prove automatic cross-store synchronisation.

## Reproduce

Install the pinned packages with `npm ci`, then `npx playwright install chromium`. Run `npm run screenshots`, inspect the captures, and run `npm run build` afterwards. The capture script uses a clearly identified preview-only app build so real screenshots can be created before the complete article build requires them.

Only the captured application is shown. No screenshot is generated by an image model, assembled from a mock or presented as user evidence. The authoritative article and README use these same files.
